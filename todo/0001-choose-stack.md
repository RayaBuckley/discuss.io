# 0001 Choose language and framework

## Problem

The project has no language, framework, or build tool.
An AI assistant cannot write code until the humans choose them.

## Cause

The project is new.

## Acceptance

- The humans record the choice in this file and delete this task.
- The repository builds with one command.
- The repository starts the application with one command.

## Notes

The UI must run in a browser or a terminal that an end-to-end test can control.
